## Sobre mim

Sou DevOps Engineer Pleno, de Pernambuco. Atuo com infraestrutura AWS, administração Linux, containers, automação e sustentação de ambientes de produção. Uso Terraform, Terragrunt, Ansible, Docker e pipelines de CI/CD para padronizar ambientes e apoiar entregas confiáveis.

Comecei no desenvolvimento backend. Essa base ajuda a investigar falhas entre aplicação, banco de dados e infraestrutura e a colaborar com times de desenvolvimento. Na Pigz, contribuí para uma modernização de infraestrutura AWS associada a uma redução de aproximadamente 60% nos custos; também trabalhei em otimizações que reduziram o tempo de resposta de funcionalidades críticas de cerca de 4 segundos para 500 ms.
